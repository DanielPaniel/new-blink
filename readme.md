# New Blink!

I made my own version of the blink-tag as a custom element.

Use cases yet to be found.

Features: 
- More settings than the original blink
- Annoying!
- Respects reduced-motion-setting

Example usage:
```
<new-blink type="default">My blinking content!</new-blink>
<script src="NewBlink.js"></script>
```

Read about the original blink on [MDN](https://developer.mozilla.org/en-US/docs/Glossary/blink_element), or [Wikipedia](https://en.wikipedia.org/wiki/Blink_element).
